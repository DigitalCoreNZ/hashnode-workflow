## System Maintenance.

APT (Advanced Package Tool) handles the installation and removal of software on Ubuntu distributions and the following commands keep the distros up-to-date.

*   From the terminal, I update my system:
    

```bash
sudo apt clean && \
sudo apt update && \
sudo apt dist-upgrade -y && \
sudo apt --fix-broken install && \
sudo apt autoclean && \
sudo apt autoremove -y
```

*   I can also go to Settings > System > Software Updates to update my system.
